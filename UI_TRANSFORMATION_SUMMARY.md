## 💡 Customization Guide

### Change Primary Color
```python
# In CSS section, change:
--primary-color: #2E86AB;  # to your color
```

### Adjust Card Padding
```python
# In CSS section, change:
.card-container {
    padding: 24px;  # to desired value
}
```

### Modify Header Gradient
```python
# In CSS section, change gradient colors:
background: linear-gradient(135deg, #2E86AB 0%, #A23B72 100%);
```
